# 🛡️ Mini SIEM – Security Information and Event Management System

An educational, beginner-friendly Security Information and Event Management (SIEM) dashboard built with Python and Streamlit.

---

## 🎯 Project Roadmap

- **Stage 1: Project Foundation** *(Completed)*: Log ingestion, custom dark SOC dashboard, baseline metrics, interactive filters.
- **Stage 2: Threat Detection Engine** *(Completed)*: Rule-based correlation engine, multi-threat detection, dynamic alert generation.

> **Note:** This project is strictly educational. It operates solely on synthetic, fictional log data and does not connect to external systems or perform real attacks.

## ⚙️ Stage 2: Security Threat Detection Engine

The detection engine (`src/detection_engine.py`) continuously analyzes incoming security event logs using 5 rule-based correlation algorithms:

### Detection Rules & Criteria

| Rule Name | Target / Focus | Default Criteria & Threshold | Assigned Severity |
| :--- | :--- | :--- | :--- |
| **RULE-01: Brute Force** | Source IP | Detects $\ge 3$ failed logins from the same source IP within a 15-minute sliding window. | `High` / `Critical` ($\ge 5$) |
| **RULE-02: Target User Failures** | Username | Detects $\ge 2$ failed logins targeting the same valid account within a 30-minute window (ignores missing/unknown users). | `Medium` / `High` (privileged) |
| **RULE-03: Suspicious IP Correlation** | Source IP | Detects $\ge 2$ suspicious events across $\ge 2$ distinct event categories from the same IP within a 60-minute window (eliminates single-category duplicates). | `High` / `Critical` (malware) |
| **RULE-04: Port Scan Reconnaissance** | Source IP | Detects repeated port scanning events ($\ge 2$ within a 15-minute sliding window) from the same source IP. | `Medium` / `High` |
| **RULE-05: Privilege Escalation** | User / Host | Flags unauthorized or anomalous privilege escalation attempts (e.g. sudo without valid ticket). | `Critical` |

### Alert Data Schema

Each alert dynamically generated by the engine includes:
- **Alert ID**: Unique identifier (e.g., `ALT-BF-001`, `ALT-PE-008`).
- **Timestamp**: Time of the triggering event.
- **Source IP**: Originating network address.
- **Username**: Target account or acting user.
- **Threat Type**: Categorized threat label.
- **Severity**: Triage priority (`Critical`, `High`, `Medium`, `Low`).
- **Detection Rule**: Formal rule designation.
- **Explanation**: Human-readable context and trigger justification.

## 🚀 Setup & Run Instructions

### 1. Prerequisites
- Python 3.10+ installed.

### 2. (Optional) Virtual Environment
```powershell
python -m venv venv
.\venv\Scripts\Activate.ps1
```

### 3. Install Dependencies
```powershell
pip install -r requirements.txt
```

### 4. Run the Mini SIEM Dashboard
```powershell
streamlit run app.py
```
Open **`http://localhost:8501`** in your browser.

### 5. Run Automated Unit Tests
```powershell
python -m unittest discover -s tests -v
```
All 16 unit tests will execute, validating data ingestion, metrics, and all 5 detection rules.
